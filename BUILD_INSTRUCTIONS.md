# Сборка APK «Помощник КИПиА»

APK собирается автоматически через GitHub Actions.

1. Открой репозиторий и вкладку **Actions**.
2. Выбери запуск **Build Помощник КИПиА APK**.
3. После успешного завершения открой этот запуск и скачай артефакт **Pomoshchnik-KIPiA-debug-apk**.
4. Распакуй ZIP артефакта — внутри будет APK для установки на Android.

Приложение содержит встроенную HTML-страницу с восемью полевыми калькуляторами и работает без интернета.
